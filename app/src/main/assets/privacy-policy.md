# Privacy Policy

Last updated: 2026-04-01

GameVault uses Firebase Analytics to understand how the app is used and to improve the product.

## What we collect

- Screen views and feature interactions
- Filter usage and button taps
- Query length for search submissions
- Domain-only information for outbound links

We do **not** collect:

- Names, emails, user IDs, or device IDs
- Raw search queries
- Personal content

## Why we collect it

We use analytics to improve app quality, prioritize features, and understand user flows.

## Your choices

You can disable analytics from the app Settings screen at any time.
